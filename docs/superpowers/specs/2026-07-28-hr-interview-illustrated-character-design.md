# HR 会谈室：精致绘本人物与第一人称构图

## 目标

重做 HRBP 会谈室的视觉主场景，使用户感到自己正坐在会议桌一侧工作：左下角是可操作、放大的电脑；宽桌横向贯穿画面；对面的小林保留合理、自然的简化坐姿，情绪则交给明确的 emoji 和谈话文案表达，避免把体验建立在复杂的角色面部动画上。

## 已确认方向

- 构图采用 A：左下角大电脑、右侧对面员工、宽桌前置。
- 视觉风格采用简化手绘角色：温暖、低饱和、深棕线稿，与当前 People Valley 场景协调。
- 不再依赖生成式位图插画；人物、场景和互动 UI 均由现有代码渲染。

## 画面设计

### 布局

1. 电脑放在左下区域，尺寸扩大到桌面高度的约 70%，覆盖部分桌缘，成为 HR 的第一人称工作界面。
2. 桌面横跨画面下方约四分之一，高度控制在 150–190px；桌腿仅作为次要环境线索，避免造成大块空白。
3. 小林位于右侧、桌子对面，坐姿完整可见至腰部或膝部；其脸部始终处在画面视觉焦点区。
4. 对话气泡位于人物左上方，避开电脑和人物面部；窗、绿植和会议室标识保持低权重背景。

### 人物与情绪

- 小林维持简化、合理的坐姿：短发、深青绿色外套、米白内搭、深灰蓝长裤、绿色会议椅，双手自然交握。
- 角色脸部只保留基础五官和中性表情，不再模拟眉眼、嘴型或说话动画。
- 面谈情绪由可读的 emoji 承担，作为对话状态的附加线索：谨慎 `😶‍🌫️`、放松 `🙂`、信任 `😊`、防御 `😟`；并与已有的文字标签同步更新。
- emoji 显示在会谈窗口的状态标签和人物旁的小型状态标识中，不遮挡人物、对话气泡或输入区域。

## 交互与状态

现有面谈逻辑不变。根据已有的信任状态，仅用 CSS 在人物容器层面做轻量变化：

- `cautious`：略微降低亮度/饱和度。
- `relaxed`、`trusting`：提升亮度并有轻微自然上移。
- `defensive`：小幅向右偏移，保留对话状态的紧张感。
- `is-speaking`：不对人物做动画；通过对话气泡的省略号与现有输入状态表达正在回应。

## 技术实现

1. 删除本轮生成的未使用人物 PNG，保留项目中已有的 SVG 简化人物实现。
2. 在 `HrApp.tsx` 增加信任状态到 emoji 的映射，并在会谈窗口和人物旁显示。
3. 在 `App.css` 末端新增一组会谈室覆盖规则：左下放大电脑、前置宽桌、简化人物的定位、emoji 状态标识和小屏响应式缩放。
4. 移除人物面部和说话动画相关的状态样式，避免角色表情成为反馈信息的重复来源。
5. 通过开发服务器和浏览器截图验证 1440×900、1024×768、390×844 三个视口，不允许人物被电脑、桌面或对话气泡遮挡。

## 验收标准

- 人物呈现为合理、统一的简化手绘角色；情绪由 emoji 与文字清楚表达，而非依赖复杂面部细节。
- 电脑位于左下并明显比现版本更大；桌面更宽且占据画面底部的主要空间。
- 桌下区域不再形成大面积无信息留白。
- 会谈文本输入、对话推进、进度和信任状态仍正常运行。
- 桌面与人物在三种目标视口均清晰、无遮挡、无横向滚动。
