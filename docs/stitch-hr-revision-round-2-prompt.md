## 五、前端合成规则

- 透明 PNG 直接分层使用。
- 如果只能获得纯绿素材，先在资源处理阶段生成透明 PNG，再供网页使用；不要在最终页面运行时依赖 CSS 混合模式。

- 人物运行时必须加载某一个独立状态文件，不能加载整张 sprite sheet 后依靠不确定的 `object-position: -50% 0` 裁切。
- OS 界面作为真实 HTML/CSS 放在 `.monitor-screen` 中，外层使用显示器屏幕开口精确裁切。
- `.monitor-screen` 的位置和尺寸必须来自同一个显示器母版坐标，不允许每个页面分别手工“估计”百分比。
- 显示器前壳位于 UI 上方，环境和桌面位于 UI 下方；层级顺序必须是：背景 → 桌面 → 屏幕 UI → 显示器前壳/底座 → 前景键盘或纸张。
